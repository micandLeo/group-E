# HCI Coursework Group-E: MSA Evaluation Project
> Module: ADS401
> Deadline: 19 Oct 2026

## Project Overview
This repository contains materials for our user evaluation of XJTLU MSA (Major Select Assistant), an AI chatbot designed for freshmen major selection.

### Research Questions
- RQ1: Can XJTLU freshmen efficiently obtain major information using MSA?
- RQ2: Do users trust answers generated by this AI agent and support major decision making?
- RQ3: What usability problems exist in the chatbot?

### Target Users
XJTLU Year 1 students who need to select their major.

## Evaluation Method
- Think-aloud usability test
- Post-task SUS questionnaire
- Semi-structured short interview
- Sampling method: Convenience sampling, 4~6 participants

## Reflection & Limitation
We ran small-scale user tests. Limitation: small sample size, convenience sampling.
The main usability issue: missing prompt guidance on homepage.
Future improvement: add example questions on agent homepage.
